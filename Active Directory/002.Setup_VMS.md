# 02. Installing the Domain Controller 

1. Use `sconfig` to :
    - Change Host name
    - Change the IP Addr. to static 
    - Change the DNS to our own IP Addr. 

2. Install the Active Directory Windows Features

```shell
Install-WindowsFeature -Name AD-Domain-Services -IncludeManagementTools
```
