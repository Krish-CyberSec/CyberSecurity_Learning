# list the contents of the current directory using the command
```
dir
```

# Some files and folders on Windows are marked as hidden, which means they don't appear in a normal listing. To show everything, including hidden items
```
dir /a
```
# to search file 
```
dir /s filename.ext
```

# to get the hostname
```
hostname
```

# to get info about system 
```
systeminfo
```
